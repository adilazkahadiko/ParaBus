録音トラック・形式

チェックした音声ごとに、1chの48 kHz Float WAVを保存します。Output 1/2は2ファイルです。VC MIXとUser / InputはPRE録音のため、通常のフェーダー・ミュートに影響されません。PENDINGと緊急停止は無音です。対象は開始時に固定し、途中参加のUserを自動追加しません。DROPPEDは録音で欠落したブロック数です。
