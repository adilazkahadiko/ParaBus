ParaBus Windows x64 v0.1.0-beta.2

公開Release: https://github.com/adilazkahadiko/ParaBus/releases/tag/v0.1.0-beta.2
脆弱性の非公開報告: https://github.com/adilazkahadiko/ParaBus/security/advisories/new

使い始める
1. 受け取ったZIPを右クリックして「すべて展開」し、新しい専用フォルダーへ展開します。
2. ParaBusフォルダー内の ParaBus.exe を開きます。ほかのEXEを開く必要はありません。
3. 通知領域の「PB」アイコンから操作画面を開きます。
4. SETUPで自分のDiscord Botと接続先を設定し、手動で接続します。
   開発者のTokenや設定は含まれていません。Bot TokenやSupport Bundleを他人へ送らないでください。
5. Mainの出力機器を選びます。Cueを使う場合はCue側の機器も選びます。
   Discordへマイクを送る場合だけPhysical InputとROUTEを設定し、TXを開始します。

Node.js等の開発ツールのインストールは不要です。Windows x64用です。
ASIOを使う場合は、機器メーカーの正規64bitドライバーを別途インストールします。
アプリはコード署名していません。SmartScreenが出た場合は、取得元を確認して判断してください。
OS全体の保護設定を変更する必要はありません。

使い始めの確認
・起動してBotへ接続できるか、参加者の音がMain/Cueで聞こえるか。
・各ユーザーのVC MIXフェーダーとMIX ON/OFFが意図どおり効くか。
・必要ならTXと録音を試し、保存した録音を再生できるか。
・画面の分かりにくい点、音切れやノイズなど、気付いた点を教えてください。
問題が出たら、時刻・操作・使用機器・画面のBUILDを控えてください。
リセット前にSupport Bundleを保存し、内容を自分で確認してから必要な情報だけ共有してください。

終了する
録音を停止して保存完了を待ち、SETUPの「ParaBus を終了」を選びます。
設定ロックをOFFにし、表示中の障害を確認する必要があります。
ブラウザーを閉じるだけではアプリは終了しません。

この版について
Node.js 22.23.4を同梱しています。
旧private履歴の検証候補1058fb681f93で、2026-10-22に約1時間の音声・録音・Discord送信を確認しました。
この番号は公開履歴のcommitではありません。
タブレット操作は再設計待ちのため、この版では提供していません。
以前にTXで一瞬のノイズ・詰まりの報告があり、原因は未特定です。
旧private候補1058fb681f93での約1時間試験では問題の報告はありませんでした。正式な安定版ではないベータ版です。
segfault-handler除去・UI整理・タブレット提供停止・依存更新後の長時間実機試験は未実施です。
多人数・別機種・SoundGrid/LV1での本番実機確認は未完了です。予備の音声経路を用意してください。
旧版に含まれていた任意のsegfault-handler/StackWalker診断機能は同梱していません。
音声DLL・Rust EXEは出自とhashを記録して再利用しています。再ビルド済みとは扱いません。
音声DSP・native DLLは元候補と同じです。旧POST設定が残る場合はSETUPに確認・解除操作を表示します。
旧設定は自動変更しません。POST復旧で音が出る場合があるため、確認してから操作してください。
元の配布候補eb206444c332ではnative読み込みと実ParaBus.exeの起動・通常終了を確認済みです。
beta.2ではundici 6.29.1・brace-expansion 1.1.21へ更新し、VCマスターをMASTER ON / MASTER MUTEDと表示します。
音声処理・nativeは変更していません。beta.2のWindows ZIP版で、メンテナーが実Discordへの接続と音声の送受信を確認しました。
短時間の試験のみで、長時間の実機試験は未実施です。
BUILD COMMITと各部品のSHA-256は同梱のcomponent-provenance.jsonを参照してください。
